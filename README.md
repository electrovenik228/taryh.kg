# Тарых.кг — Образовательная платформа по истории Кыргызстана

Интерактивная веб-платформа для изучения истории, культуры и государственной символики Кыргызской Республики.

## Быстрый старт

```bash
# 1. Создать виртуальную среду и установить зависимости
python3 -m venv venv
source venv/bin/activate          # Linux/Mac
# или: venv\Scripts\activate      # Windows

pip install -r requirements.txt

# 2. Применить миграции и загрузить начальные данные
python manage.py migrate
python manage.py loaddata fixtures/initial_data.json

# 3. Создать администратора
python manage.py createsuperuser

# 4. Запустить сервер
python manage.py runserver
```

Открыть в браузере: http://127.0.0.1:8000/

**Уже созданный тестовый администратор:** `admin` / `admin123`  
**Панель администратора:** http://127.0.0.1:8000/admin/

## База данных

По умолчанию используется **SQLite** (файл `db.sqlite3`).

Для PostgreSQL создай файл `.env` по образцу `.env.example` и измени `DB_ENGINE=postgresql`.

## Добавление контента

Весь контент управляется через Django Admin (`/admin/`):

- **Исторические периоды** — добавляй эпохи и события
- **Личности** — биографии с фото
- **Символика** — описания флага, герба, гимна
- **Тесты** — создавай вопросы и ответы
- **Статистика** — числа для главной страницы

## Технологии

- **Backend:** Django 5.0, SQLite/PostgreSQL
- **Frontend:** Django Templates, TailwindCSS (CDN), Alpine.js
- **Хранение файлов:** локально (media/)
- **Анимации:** CSS keyframes + Alpine.js transitions
